# DreamIsland

«Динамический остров» для Windows 10/11 в стиле iPhone: маленькая капсула сверху экрана, которая показывает, что играет, дату и важные события. Лёгкая (десятки мегабайт ОЗУ), на C# и WPF.

## Возможности

**Музыка** (Spotify, Яндекс Музыка, браузер, любые плееры из медиа-панели Windows)
- обложка, название и исполнитель, бегущая строка для длинных названий;
- кольцо прогресса вокруг обложки в свёрнутом виде, полоса со временем и перемоткой в раскрытом;
- кнопки «назад / пауза / вперёд», клик по острову — пауза, клик по обложке — следующий трек;
- цвет эквалайзера и свечения берётся из обложки;
- **живой эквалайзер**: полоски и свечение двигаются под реальный звук (басы / середина / верха).

**Индикаторы** (всегда на виду, рядом с датой или музыкой)
- раскладка клавиатуры, микрофон (вкл/выкл), VPN;
- **точка записи**: голубой кружок — микрофон используется программой, фиолетовый ромб — камера;
- REC / LIVE из OBS Studio со временем.

**Плашки событий**
- громкость (колёсиком мыши по острову; **Shift + колёсико** меняет громкость только SoundCloud), микрофон, Caps Lock, раскладка;
- подключение и отключение наушников и флешек;
- VPN включён / выключен;
- скриншот сохранён (с миниатюрой), текст скопирован;
- в проводнике: сколько файлов выделено, сколько удалено или перемещено (на 1,5 секунды);
- программа начала использовать микрофон или камеру.

**Инструменты**
- таймер, секундомер, помодоро (25/5);
- история буфера обмена: после копирования наведи на остров — появится список из 5 последних фрагментов, клик вставляет выбранный;
- автозапуск с Windows.

Всё включается и выключается в меню по правому клику на острове.

## Требования
- Windows 10 (19041+) или Windows 11;
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) (для запуска) или .NET SDK 8+ (для сборки).

## Запуск из исходников
```
dotnet run
```

## Сборка exe
Двойной клик по `publish.bat` — готовый файл появится в папке `publish\DreamIsland.exe`.

## Настройка
Правый клик по острову открывает меню: таймеры, переключатели функций, автозапуск, выход.
Настройки хранятся в `%AppData%\DreamIsland\settings.txt`.

### OBS
1. В OBS: **Инструменты → Настройки сервера WebSocket** — включить сервер (порт 4455).
2. В меню острова включить **«Следить за OBS»**; если в OBS включён пароль, указать его в пункте **«OBS: пароль…»**.

Пароль хранится в `settings.txt` открытым текстом на твоём компьютере.

### VPN
Остров читает файл `%AppData%\DreamVPN\status.json`, который пишет приложение VPN. Формат:

```json
{
  "state": "connected",
  "connected": true,
  "server": "название сервера",
  "country": "страна",
  "core": "sing-box",
  "pid": 1234,
  "startedAt": "2026-01-01T12:00:00Z",
  "updatedAt": "2026-01-01T12:00:05Z"
}
```

`state` — `connected`, `connecting`, `disconnected` или `error`; `pid` — процесс приложения VPN (по нему остров понимает, что программа закрылась аварийно). Если файла нет, остров ищет запущенные `sing-box`, `xray` и `tun2socks`.

### Микрофон с аппаратной кнопкой mute
Некоторые микрофоны (например, Fifine AM8) глушат звук внутри себя, и Windows об этом не знает. Для них включи **«Следить за микрофоном (по звуку)»**: остров считает микрофон выключенным, если приходит полная тишина. Чтобы подобрать порог, есть режим **«Показать уровень микрофона (отладка)»**.

## Обновления

Остров умеет обновляться сам из GitHub Releases:
- раз в 12 часов (и через 30 секунд после запуска) он проверяет последний релиз;
- если версия новее, скачивает `DreamIsland.exe` в фоне и ставит его **при следующем запуске**, чтобы не перезапускаться посреди игры;
- в меню острова есть пункт **«Проверить обновления»**: скачивает и ставит сразу, с перезапуском.

Настройка:
1. В меню острова выбери **«Репозиторий обновлений…»** и впиши `твой_логин/DreamIsland` (или поменяй `DefaultRepo` в `Updater.cs`).
2. Чтобы выпустить версию, поставь тег и отправь его:
   ```
   git tag v1.0.1
   git push origin v1.0.1
   ```
   GitHub Actions соберёт `DreamIsland.exe` и приложит его к релизу.

Автоустановка работает только для собранного exe (`publish.bat` или релиз с GitHub). При запуске через `dotnet run` остров только сообщает о новой версии.
Скачанный файл проверяется (размер, формат и контрольная сумма, если GitHub её отдаёт), а адрес загрузки должен быть на github.com. Остров доверяет тому, что лежит в релизах твоего репозитория, поэтому включи двухфакторную защиту на GitHub-аккаунте.

## Приватность
- **Caps Lock**: используется глобальный хук клавиатуры, но программа смотрит только на эту одну клавишу, остальные игнорируются и нигде не сохраняются.
- **Буфер обмена**: история хранится только в памяти и очищается при выходе; не сохраняется ничего, что менеджер паролей пометил как «не сохранять». Историю можно отключить или очистить в меню.
- **Микрофон по звуку и живой эквалайзер**: звук анализируется на лету (считается только громкость), нигде не записывается и не отправляется.
- **Точка записи** читает журнал приватности Windows (раздел «Конфиденциальность → Микрофон / Камера»).
- Остров не отправляет данные в интернет.

## Известные ограничения
- В играх в эксклюзивном полноэкранном режиме окна поверх игры не видны (нужен режим «окно без рамки»).
- Проводные наушники в разъём материнской платы могут не определяться как «подключено» (Windows у них не меняет имя устройства).
- Скриншоты определяются в папке `Изображения\Screenshots` (куда их сохраняет Win+PrintScreen).
- Если у плеера нет данных о длительности трека, прогресс и перемотка недоступны.
