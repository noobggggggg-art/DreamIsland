# DreamIsland

[English](README.md) | **Русский**

«Динамический остров» для Windows 10/11 в стиле iPhone: маленькая чёрная капсула сверху экрана, которая показывает, что играет, дату и важные события. Лёгкая (десятки мегабайт ОЗУ), написана на C# и WPF.

> **Сделан для [DreamVPN](https://github.com/noobggggggg-art/DreamVPN).** Индикатор VPN и плашки про VPN работают **только с DreamVPN**. Другие VPN-клиенты не поддерживаются (см. [VPN](#vpn-только-dreamvpn)). Всё остальное работает само по себе.

## Возможности

**Музыка** (Spotify, YouTube Music, браузер, любые плееры из медиа-панели Windows)
- обложка, название и исполнитель, бегущая строка для длинных названий;
- кольцо прогресса вокруг обложки в свёрнутом виде, полоса со временем и перемоткой в раскрытом;
- кнопки «назад / пауза / вперёд»; клик по острову ставит на паузу, клик по обложке включает следующий трек;
- цвет эквалайзера и свечения берётся из обложки;
- **живой эквалайзер**: полоски и свечение двигаются под реальный звук (басы / середина / верха).

**Видео** (любой плеер, который сообщает Windows о воспроизведении, и видео в браузере)
- остров **«Эмоции»**: столбики, свечение и вспышки следуют за звуком и ритмом, остров подпрыгивает на бочку;
- цвет и вспышки следуют за **картинкой** видео (главный цвет, смена сцены, стробоскоп);
- две анимированные **колонки** выезжают в чёрные полосы по бокам вертикальных видео и пульсируют под музыку.

**TeamSpeak 3**
- кто говорит, состояние микрофона и звука, название сервера, число людей, громкость по Alt + колёсико.

**Загрузки**
- проценты, скорость и уведомление «Готово» для загрузок **Steam** и **Epic Games Launcher**.

**Индикаторы** (всегда на виду, рядом с датой или музыкой)
- раскладка клавиатуры, микрофон (вкл / выкл), VPN (DreamVPN);
- **точка записи**: голубой кружок — микрофон используется программой, фиолетовый ромб — камера;
- REC / LIVE из OBS Studio со временем.

**Плашки событий**
- громкость (колёсиком мыши по острову; **Shift + колёсико** меняет громкость только SoundCloud), микрофон, Caps Lock, раскладка;
- подключение и отключение наушников и флешек;
- VPN подключён / отключён;
- скриншот сохранён (с миниатюрой), текст скопирован;
- в проводнике: сколько файлов выделено, удалено или перемещено (на 1,5 секунды);
- программа начала использовать микрофон или камеру;
- загрузка в Steam / Epic началась, дошла до очередных 10 % или закончилась.

**Инструменты**
- таймер, секундомер, помодоро (25/5);
- **будильники** на время суток (дни повтора, подпись, мелодия, отсрочка кликом по острову) и **таймер на своё время** (часы / минуты / секунды) — вкладка «Будильник» в окне настроек;
- история буфера обмена: скопируй, наведи на остров в течение 8 секунд — появятся 5 последних фрагментов, клик вставляет выбранный;
- автозапуск с Windows;
- автообновление с GitHub.

Всё включается и выключается в меню по правому клику на острове.

## Требования
- Windows 10 (19041+) или Windows 11;
- [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0).

## Установка
1. Скачай `DreamIsland.exe` из [последнего релиза](https://github.com/noobggggggg-art/DreamIsland/releases/latest).
2. Положи его в постоянную папку, куда можно писать (не `Program Files`), и запусти.
3. По желанию: правый клик по острову → **Запускать вместе с Windows**.

## Сборка из исходников
```
dotnet run
```
или сборка одного exe-файла:
```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```
Релизы собирает GitHub Actions автоматически, когда отправляется тег `v*`.

## Обновления

DreamIsland сам обновляется из [Releases](https://github.com/noobggggggg-art/DreamIsland/releases) этого репозитория:
- через 30 секунд после запуска и затем раз в 12 часов он проверяет, есть ли релиз новее;
- если есть, скачивает `DreamIsland.exe` в фоне и устанавливает его **при следующем запуске острова**, чтобы не перезапускаться посреди игры;
- пункт меню **Проверить обновления** скачивает и ставит сразу, с перезапуском.

Источник обновлений зашит в программу и в настройках не меняется. Автоустановка работает только для собранного exe (релиз или `dotnet publish`); при запуске через `dotnet run` остров лишь сообщает, что есть новая версия. Скачанный файл проверяется (размер, формат и контрольная сумма, если GitHub её отдаёт), а адрес загрузки должен быть на github.com. Обновления можно отключить в меню.

Как выпустить новую версию:
```
git tag v1.2.0
git push origin v1.2.0
```

## VPN (только DreamVPN)

Индикатор и плашки VPN сделаны для [DreamVPN](https://github.com/noobggggggg-art/DreamVPN) и **не работают с другими VPN-клиентами**. Остров читает файл `%AppData%\DreamVPN\status.json`, который пишет DreamVPN:

```json
{
  "state": "connected",
  "connected": true,
  "server": "название сервера",
  "country": "страна",
  "core": "sing-box",
  "pid": 1234,
  "startedAt": "2026-01-01T12:00:00Z",
  "updatedAt": "2026-01-01T12:00:05Z"
}
```

`state` — `connected`, `connecting`, `disconnected` или `error`; `pid` — процесс DreamVPN (по нему остров замечает аварийное закрытие). Если файла нет, остров ищет запущенные процессы `sing-box`, `xray` и `tun2socks`. Это запасной вариант для ядер DreamVPN, а не поддерживаемый способ определять другие VPN.

## Прочая настройка

### Острова
У DreamIsland четыре «острова», которые сменяют друг друга:
1. **Обычный** (дата и индикаторы), когда ничего не играет;
2. **Музыка**, когда что-то играет;
3. **TeamSpeak 3**, пока ты подключён к серверу (заменяет остров музыки);
4. **Эмоции**, пока идёт видео (наведи на остров, чтобы вернуть кнопки музыки).

### TeamSpeak 3
Показывает, кто говорит, включены ли твои микрофон и звук, и название сервера (можно задать своё короткое название в меню). Пока кто-то говорит, остров светится зелёным и «дышит». При наведении видны полная дата и время, VPN, раскладка и оба микрофона (TeamSpeak и Windows). **Alt + колёсико** над островом меняет громкость самого TeamSpeak.
1. В TeamSpeak 3: **Tools → Options → Addons → Plugins** → включи **ClientQuery**, нажми **Settings** и скопируй **API key**.
2. В меню острова выбери **«TeamSpeak 3: API-ключ…»** → вставь ключ, затем включи **«Следить за TeamSpeak 3»**.

Всё идёт через локальный плагин ClientQuery (`127.0.0.1:25639`), ничего не покидает твой компьютер.

### Эмоции (видео)
Когда идёт видео (остров узнаёт его по типу медиа у плеера, по расширению файла, например `.mov`, или по названию плеера), остров превращается в живой визуализатор: столбики следуют за спектром, цвет — за тембром звука, свечение пульсирует на бочку, а на малый барабан остров вспыхивает. Анимацию выбирают в меню: *Авто, Спектр, Пульс, Вспышка*. Остров слушает только звук системы (ничего не записывается).

**Анализ картинки** (меню: *Эмоции: цвет и вспышки по картинке видео*): пока идёт видео, остров около 8 раз в секунду берёт крошечные кадры основного экрана 96×54, только чтобы выбрать главный цвет, заметить смену сцены или стробоскоп и найти чёрные полосы по бокам. Кадры нигде не сохраняются и никуда не отправляются. Если видео защищено от записи и на экране чёрный кадр, остров возвращается к цветам по звуку.

**Колонки** (меню: *Эмоции: колонки в чёрных полосах по бокам*): если у видео по бокам чёрные полосы (например, видео с телефона на широком экране), в них выезжают две маленькие колонки, берут цвет видео и пульсируют на бочку. Они не ловят клики и скрыты от захвата экрана, поэтому в записи OBS их не будет. Полосы уже примерно 56 пикселей игнорируются. Если звук стерео, каждая колонка следит за своим каналом (гитарный удар слева сильнее толкает левую колонку). Когда музыка несколько секунд подряд нарастает, колонки «накачиваются» (кольца сжимаются, свечение копится), а на самом взрыве (дропе) обе колонки и остров вспыхивают одновременно. Ещё: каждая колонка берёт цвет со своего края картинки (бледное видео в дыму оставляет цвет по музыке), на чёрной полосе вокруг колонок мягкий цветной свет, на самых сильных ударах разлетаются 8–12 искр, а когда видео на паузе, колонки остаются, тускнеют и медленно «дышат». В меню: *Эмоции: стиль колонок* — Неон, Ретро, Минимализм. Размытие нигде не используется; при включённой «Экономии видеопамяти» свет и искры выключаются.

**Эффекты колонок** (неон — все, ретро — мягкая часть, минимализм — только затишье, волны и искры): по бокам корпуса горят LED-шкалы из 16 полос спектра своего канала; из колонки расходятся лучи прожекторов, которые качаются, мигают на верхах и раскрываются веером на дропе; на диффузоре расходится рябь (кимати); по рамке корпуса бежит огонёк, на нарастании он ускоряется, а на дропе замыкается в вспыхивающую обводку; на нарастании светлячки слетаются к колонке, а на дропе разлетаются салютом; на малом барабане корпус на пару кадров «глитчит» цветными полосами; на дропе по полосе идёт ударная волна из двух колец с цветовым разносом (красное и синее) и яркая вспышка. При включённой «Экономии видеопамяти» лучи, светлячки, глитч и ударная волна выключаются, остаются LED-шкалы, рябь и огонь.

**Затишье перед дропом.** Если трек был громким, а потом резко стих (брейкдаун), колонки и остров гаснут и замирают, свет втягивается внутрь («вдох»), а на первом сильном ударе после затишья дроп получается заметно сильнее обычного.

**Чувствительность** (меню *Эмоции: чувствительность*): *Тихо* — только самые сильные моменты, *Обычно* — как раньше, *Жёстко* — реагирует почти на всё. Пресет меняет пороги нарастания, дропа, затишья и искр (раньше это были константы в коде) и запоминается.

**Колонки поверх картинки** (меню *Эмоции: колонки поверх картинки, если нет чёрных полос*, выключено по умолчанию): если у видео нет полос, две уменьшенные полупрозрачные колонки висят у левого и правого края экрана поверх картинки.

**Отладочная панель** (меню *Эмоции: отладочная панель с числами*, после перезапуска всегда выключена): маленькое окно в левом верхнем углу показывает громкость, интенсивность, нарастание, рост энергии и порог, всплеск и порог дропа, затишье, сколько ещё можно поймать дроп, число дропов, баланс каналов и счётчики ударов. По этим числам удобно подобрать пресет под свои видео. Клик по панели копирует числа и историю за последнюю минуту в буфер обмена (удобно прислать разработчику). Панель не забирает фокус и не попадает в захват экрана.

**Интерфейс DreamIslands.** Правый клик по острову вместо обычного меню открывает свой интерфейс: в центре экрана появляются четыре кубика, сходятся, превращаются в прямоугольник, растут вширь и вверх-вниз, затем сверху вниз появляются разделы. Оформление чёрное, текст белый, края у разделов, кнопок и переключателей фиолетовые, сверху по центру надпись DreamIslands. Разделы: **Часы** (таймер, секундомер, помодоро, пауза/продолжить, остановить), **Звук** (включение микрофона по звуку, отладка микрофона), **Удобство** (живой эквалайзер, эмоции, плеер), **Сервисы** (TeamSpeak 3, Steam/Epic, проводник, буфер обмена, скриншоты, OBS), **Статистика** (время в выбранных программах, напоминание о перерыве), **Настройки** (показ подключённых устройств, запуск с Windows, версия, автообновление, точка записи, экономия видеопамяти). Esc, крестик или клик мимо закрывают окно. Обычное контекстное меню осталось в коде как «движок»: интерфейс управляет его пунктами, поэтому вся логика прежняя.

**Микшер громкости** (раздел «Звук»): у каждой программы свой ползунок и кнопка «Без звука», играющие сверху (рядом с ними светится точка). Программы берутся со всех устройств вывода, а Windows применяет громкость программы раньше, чем звук попадает в Voicemeeter, поэтому микшер работает и через него.

**Статистика** (вкладка): вы сами выбираете, какие программы отслеживать. Готовые Minecraft и Roblox можно включать и выключать, любую другую запущенную программу можно добавить кнопкой «Выбрать из запущенных» (и удалить крестиком). Остров замечает запуск по имени процесса, в программу не вмешивается, показывает время за сегодня и за 7 дней по каждой программе и суммарно и напоминает о перерыве, если одна программа работает дольше выбранного времени (выкл, 30 минут, 1 час, 1,5 часа, 2 часа). Для Minecraft на Java игру определяют по заголовку окна (Minecraft, Lunar Client, Badlion, Feather).

### Загрузки Steam и Epic
Когда в Steam или Epic Games Launcher что-то качается, остров показывает всплывашку с названием игры, процентами и скоростью: в начале, на каждые 10 % и по окончании («Готово»). Пункт меню *Загрузки: показать сейчас* показывает текущую загрузку по запросу, пункт *Показывать загрузки Steam / Epic* включает и выключает слежение.

Остров только читает файлы самих лаунчеров, в сеть ничего не отправляет. У Steam проценты точные (из `appmanifest_*.acf`), но Steam записывает их в файл не каждую секунду, поэтому цифра обновляется скачками. У Epic официального файла прогресса нет, поэтому проценты оценочные: размер папки недоустановленной игры относительно полного размера.

### Экономия видеопамяти
Пункт **«Экономия видеопамяти (после перезапуска)»** переключает WPF на программную отрисовку, убирает размытие свечения и ограничивает анимации 30 кадрами в секунду. Полезно, если играм не хватает видеопамяти.

### OBS
1. В OBS: **Инструменты → Настройки сервера WebSocket** → включить сервер (порт 4455).
2. В меню острова включить **«Следить за OBS»**; если в OBS включён пароль, ввести его в **«OBS: пароль…»**.

Пароль хранится в `%AppData%\DreamIsland\settings.txt` открытым текстом на твоём компьютере.

### Громкость SoundCloud (Shift + колёсико)
Зажми Shift и крути колёсико над островом: меняется громкость **только SoundCloud** (его собственная громкость, как в «Микшере громкости» Windows), системная не трогается. Остров ищет приложение SoundCloud; если его нет, берёт браузер, который прямо сейчас воспроизводит звук. Windows даёт громкость на уровне браузера, а не вкладки, поэтому в браузере меняется всё, что он играет.

### Микрофон с аппаратной кнопкой mute
Некоторые микрофоны (например, Fifine AM8) глушат звук внутри себя, и Windows об этом не знает. Для них включи **«Следить за микрофоном (по звуку)»**: остров считает микрофон выключенным, если приходит полная тишина. Режим **«Показать уровень микрофона (отладка)»** помогает подобрать порог.

## Приватность
- **Caps Lock и Delete**: используется глобальный хук клавиатуры, но программа смотрит только на эти две клавиши (Delete помогает отличить «удалено» от «перемещено» в проводнике). Остальные клавиши игнорируются, ничего не сохраняется.
- **Буфер обмена**: история хранится только в памяти и очищается при выходе; то, что менеджер паролей пометил как «не сохранять», пропускается. Историю можно отключить или очистить в меню.
- **Живой эквалайзер и микрофон по звуку**: звук анализируется на лету (считается только громкость), нигде не записывается и никуда не отправляется.
- **Точка записи** читает журнал приватности Windows (Параметры → Конфиденциальность → Микрофон / Камера).
- **Картинка экрана** (только режим видео): пока работает остров «Эмоции», в памяти около 8 раз в секунду берутся крошечные кадры основного экрана 96×54, чтобы выбрать цвет и найти чёрные полосы. Они нигде не сохраняются и никуда не отправляются. Отключается в меню.
- **Загрузки Steam / Epic**: читаются только файлы самих лаунчеров на твоём компьютере.
- **Сеть**: единственный запрос в интернет — проверка обновлений на `api.github.com` (и загрузка с GitHub). Её можно отключить в меню. С OBS остров общается только на твоём компьютере (`127.0.0.1`).

## Известные ограничения
- Windows не рисует окна поверх игр в эксклюзивном полноэкранном режиме; нужен режим «окно без рамки».
- Проводные наушники в разъём материнской платы могут не определяться (Windows не меняет имя устройства).
- Скриншоты определяются в папке `Изображения\Screenshots` (куда их сохраняет Win+PrintScreen).
- Плашки проводника видят только файлы, ушедшие из открытой папки; при нескольких вкладках в одном окне выделение может считаться не с той вкладки.
- Если плеер не отдаёт длительность трека, прогресс и перемотка недоступны.
- Колонки намеренно скрыты от захвата экрана, поэтому их нет в OBS и на скриншотах.
- У Epic Games Launcher нет официального файла с прогрессом: проценты оценочные, а при обновлении уже установленной игры их может не быть.
- Steam записывает прогресс загрузки на диск не каждую секунду, поэтому его проценты обновляются скачками.
- В режиме видео анализируется только основной экран.
